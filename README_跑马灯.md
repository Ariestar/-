# 七段流动跑马灯（往返 + 残影）

## 效果

- 数码管上一个亮点 **先过去，到头再折返回来**（不是转圈）
- 默认较快（约 50 步/秒），身后带 **5 级残影拖尾**
- LED 同步往返拖尾

残影层次（从龙头到尾巴）：

```text
8  →  0  →  5  →  -  →  ·  →  灭
亮                        淡
```

## 开关

| 开关 | 功能 |
|------|------|
| SW1 SW0 = 00 | 最快（默认，残影最明显） |
| SW1 SW0 = 01 | 快 |
| SW1 SW0 = 10 | 中 |
| SW1 SW0 = 11 | 慢 |
| SW2 = 1 | 暂停 |

## Vivado

1. Design Sources 只加 `marquee.v`
2. 顶层设为 **marquee**
3. 约束用 `icf.xdc`
4. Synthesis → Implementation → Bitstream → Program

## 若还觉得慢

把 `move_max` 里 `2_000_000` 再改小，例如 `1_000_000`（约 100 步/秒）。
