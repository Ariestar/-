# 七段数码管“流动跑马灯”

## 两件事别混

| 概念 | 是什么 | 作用 |
|------|--------|------|
| **动态扫描** | 驱动方法 | 同一时刻只点亮 1 位，高速轮扫，人眼看成多位同时亮 |
| **流动跑马灯** | 显示效果 | 亮点/图案在数码管上从一端“流”到另一端 |

本实验要的是第二种效果；第一种只是实现它的底层手段。

## 上板现象

- 默认：8 位数码管上有一个 **“8”** 在左右循环流动，其余位熄灭
- `SW1=1`：变成 3 位点拖尾，更像流水
- 上方 16 个 LED 同步单点（或拖尾）追逐
- `SW0` 改方向，`SW2=1` 暂停

## 文件

- `marquee.v`：顶层（Vivado Design Sources 只用这个）
- `marquee_tb.v`：仿真（不要设为 Top）
- `icf.xdc`：约束

## Vivado

1. 顶层设为 **marquee**
2. Synthesis → Implementation → Bitstream
3. Hardware Manager 烧录

## 开关

| 开关 | 功能 |
|------|------|
| SW0=0/1 | 向左 / 向右流动 |
| SW1=0/1 | 单点 / 三点拖尾 |
| SW2=1 | 暂停 |
